# Label the mode switch so three modes read as one choice

- Situation: three mutually exclusive modes offered above the one button that runs them.
- Proposed: a row of peer buttons, one per mode, beside a generic `Run`.
- Chosen: a segmented control under a visible `Mode` label with a filled selection, and the button beside it names the selected mode's act.
- Why: "Three modes read as three actions until the switch says it is one. The label and the filled selection are what make 'Analyse' a choice; the button beside the switch names that act rather than saying 'Run'."
- Pattern: copy--make-exclusive-modes-read-as-one-choice
- Status: ruling
