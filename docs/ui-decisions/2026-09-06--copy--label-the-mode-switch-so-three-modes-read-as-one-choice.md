# Label the mode switch so three modes read as one choice

- Situation: three mutually exclusive modes offered above the one button that runs them.
- Proposed: a row of peer buttons, one per mode, beside a generic `Run`.
- Chosen: a segmented control under a visible `Mode` label with a filled selection, and the button beside it names the act — `Write & run`, `Change & run`, `Run`. The switch names the mode in the reader's verbs (`Write`, `Change`, `Run`) while the stored values (`analyse`, `refine`, `rerun`) stay as they are.
- Why: "Three modes read as three actions until the switch says it is one." The switch is a choice and the button is what happens, so they are named differently on purpose.
- Pattern: copy--make-exclusive-modes-read-as-one-choice
- Status: ruling
