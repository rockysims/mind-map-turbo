# The background menu's counts sit in parentheses, and Paste names its count

- Situation: the two items of the background menu (`2026-10-19--copy--the-background-menu-offers-paste-and-copy-n-only.md`, now amended by this file).
- Proposed: "Copy N" for the selection and a bare "Paste".
- Chosen: "Copy (N)" when more than one node is selected, and "Paste (N)" where N is the number of nodes the clipboard holds — read when the menu opens, from the tab's own last copy at once and from the system clipboard as soon as it answers. When nothing readable is there the item reads "Paste" and says why it cannot act, as before. "Cut edges" is unchanged.
- Why: no reason given ("Copy [number]" → "Copy ([number])"; "Paste" → "Paste ([number])").
