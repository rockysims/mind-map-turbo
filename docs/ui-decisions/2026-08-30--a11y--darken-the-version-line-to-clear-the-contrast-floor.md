# Darken the secondary line to clear the contrast floor

- Situation: a secondary line set under a heading, greyed to sit behind it.
- Proposed: `#94a3b8` on near-white, which read at about 2.4:1.
- Chosen: `#64748b`, about 4.8:1.
- Why: the darker grey "still sits clearly behind the heading, which is all the line was ever asking for" — de-emphasis without dropping below the 4.5:1 floor.
- Pattern: a11y--hold-body-text-at-the-4-5-1-contrast-floor
- Status: ruling
