# Several add-ons coexist on one node

- Situation: a node gaining typed add-ons (task, AI, attachments) that could have been made mutually exclusive.
- Proposed: one add-on per node.
- Chosen: "Several; all add-ons coexist on one node."
- Why: "Forbidding would cost a rule with no case behind it. Confirmed by the user 2026-09-04."
- Pattern: none
- Status: ruling
