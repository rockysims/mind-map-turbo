## Claude Code specifics

The guide above is shared with other agent tools. These notes are for Claude Code only.

- **UI work.** Use the `ui-patterns` skill whenever you create or change anything a user sees or operates, and log the owner's rulings to `docs/ui-decisions/` as it describes. The skill is installed per-user, not in this repo; without it, still read `docs/ui-decisions/` before changing UI.
